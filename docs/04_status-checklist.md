### 未検証（Netlify 本番環境でのみ確認できるもの）

公開後、最初の会員を発行する前に、自分用のテスト会員で以下を確認してください（第2節）。

- Netlify Blobs への実際の読み書き（テストでは同じコードをメモリ上の保存先で実行しています）
- 本番での Edge Function の動作（作業環境から Netlify のサーバーに接続できないため、関数設定の読み込みは本番で確認が必要です）
- 記録提出のアップロード（Edge Function が受け取れる最大サイズは未確認。5MBに制限しています）
- Netlify Forms の受信と通知メール
- 実機（iPhone・Android）での表示・ファイル選択

### 未実装（意図的に実装していないもの）

| 機能 | 理由・代わりの運用 |
|---|---|
| オンライン決済・自動の入金確認 | 決済サービスが未指定のため、架空の決済処理は作っていません。銀行振込を手作業で確認し、確認後に会員IDを発行します |
| 申込み・会員の管理画面（Web） | 管理者のパソコンからコマンドで操作します（安全な管理画面には別途の認証設計が必要なため） |
| 記録提出・申込みの自動通知メール | メール送信サービスの契約が必要なため未実装。提出は `npm run submissions -- list` で確認します |
| 会員が自分でパスワードを変更・再設定する機能 | 管理者が再発行します（本人確認をメールで行う運用） |
| 毎日の記録をWebフォームに入力する機能 | 紙（PDF）で記録し、月末に提出する運用です |
| ログアウト時のサーバー側セッション失効 | ログアウトはブラウザのCookieを削除します。端末の紛失など、ほかの端末のログインも無効にしたいときは、パスワード再発行で全ログインを無効化できます。ログインは最長12時間で自動的に切れます |

- [ ] **料金**：3,300円／9,800円／27,800円（今回のサイト用の提案料金。既存の販売価格との整合）
