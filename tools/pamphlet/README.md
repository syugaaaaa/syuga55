# 会社案内パンフレット（A4横・巻き三つ折り）

```bash
python3 tools/pamphlet/make_pamphlet.py                          # src/content/site.mjs の url をQRコードに使用
python3 tools/pamphlet/make_pamphlet.py --url https://独自ドメイン/  # URLを指定
```

出力は `tools/pamphlet/out/`（Git には含めません）。

| ファイル | 用途 |
|---|---|
| `pamphlet_print.pdf` | 印刷入稿用。303×216mm（仕上がり297×210mm＋塗り足し各3mm）。1ページ目＝表面、2ページ目＝中面 |
| `pamphlet_preview.pdf` | 社内確認用。仕上がりサイズ、折り位置の点線入り（入稿には使わない） |

## 折り（巻き三つ折り）

- 表面：左から 97mm（内側に折り込む面）｜100mm（裏表紙）｜100mm（表紙）
- 中面：左から 100mm｜100mm｜97mm
- 印刷会社には「A4巻き三つ折り、折り込み面97mm」と伝えてください。

## 印刷前の確認

- **QRコードのリンク先**：サイトのURLが仮（netlify.app）のままの場合は、独自ドメイン決定後に `--url` を付けて作り直してください。印刷前に、刷り見本をスマートフォンで読み取って確認してください。
- 料金・会社情報は、Webサイト（`src/content/site.mjs`）と同じ内容です。サイト側を変更したら、このスクリプト内の文面も合わせて更新してください。
- 写真は生成画像で、パンフレットに「掲載している写真はイメージです」と記載しています。画像の解像度は、全幅に使う部分で約200dpi相当です。より高精細な印刷が必要な場合は、高解像度の画像に差し替えてください（`images/`）。
- フォントはPDFに埋め込み済みです。印刷会社によってはアウトライン化したデータを求められる場合があります。その場合はご相談ください。
