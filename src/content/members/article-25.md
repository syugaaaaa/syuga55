「運動を続けたいのに、いつも途中でやめてしまう」。そんな悩みを持つ方は少なくありません。でも、続かなかったのは、意志が弱いからでも、運動が向いていないからでもありません。多くの場合、選んだ方法やタイミングが、自分に合っていなかっただけなのです。

30日間、体を動かした記録をつけてみると、「続けやすい時間帯」「続けやすい活動」「続かなかった理由」が見えてきます。記録は、自分に合った続け方を見つけるためのヒントの宝庫です。この記事では、30日間の運動記録を振り返り、自分に合った運動の続け方を見つける方法を紹介します。

## 30日間の記録を整理する

まずは、30日間の記録を見返しながら、次の表を埋めてみましょう。

| 項目 | 記入欄 |
|---|---|
| 体を動かせた日数 | 日／30日 |
| 一番多かった活動 |  |
| 続けやすかった時間帯 |  |
| 動けなかった日に多い理由 |  |
| 体の変化・気分の変化 |  |
| 一番楽しかった・気持ちよかった活動 |  |

「体を動かせた日数」が少なくても、がっかりする必要はありません。記録を続けられたこと自体が、大きな成果です。大切なのは、数ではなく、記録から何が見えるかです。

## 自分のタイプを考えてみる

記録を見返すと、自分が体を動かしやすい「タイプ」が見えてきます。

| タイプ | 特徴 | 続けやすい工夫 |
|---|---|---|
| 朝型 | 朝のほうが体を動かしやすい | 起床後のストレッチや朝の散歩 |
| すきま型 | まとまった時間より、こまめに動くほうが合う | 1日数回、5分の活動を積み重ねる |
| 予定型 | 予定に入っていると実行しやすい | カレンダーに曜日と時間を書き込む |
| 仲間型 | 誰かと一緒だと続けやすい | 家族や友人と散歩の約束をする |
| ながら型 | 何かと組み合わせると続けやすい | 音楽やラジオを聴きながら歩く |

当てはまるタイプは1つでなくても構いません。自分のタイプが分かると、これからの計画を立てやすくなります。たとえば、朝型の方が夜に運動しようと頑張っても、なかなか続かないかもしれません。自分のタイプに合った方法を選ぶことが、続けるための近道です。

## 続かなかった理由と対策

記録の中で、体を動かせなかった日の理由を振り返ってみましょう。よくある理由と、その対策を紹介します。

- 時間がない→5分でできるメニューに切り替える。まとまった時間でなく、すきま時間を活用する
- 天気が悪い→雨の日用の室内メニュー（ストレッチ、足踏み、家事）を用意しておく
- 疲れている→「今日はストレッチだけ」の日をつくり、ゼロにしない
- 飽きた→散歩のコースを変える、新しい活動を試してみる
- 忘れていた→すでにある習慣とセットにする、通知を設定する
理由が分かれば、対策は意外とシンプルです。次の30日間では、一番多かった理由への対策を1つ取り入れてみましょう。

## 体の変化・気分の変化に目を向ける

30日間で、体や気分にどんな変化があったかも振り返ってみましょう。「階段が少し楽になった」「肩こりが気にならなくなった」「体を動かした日は気分が良い」など、小さな変化でも構いません。こうした変化に気づくことが、続ける動機になります。

## 次の30日間の計画

振り返りをもとに、次の30日間の計画を1行で書きましょう。

例：「平日は昼休みに10分歩き、雨の日は自宅でストレッチ5分」

例：「朝型なので、起きたら布団の中で伸びをして、週3回は朝に15分散歩する」

計画は、自分のタイプと、続かなかった理由への対策を組み合わせてつくると、より続けやすくなります。

## まとめ

自分に合った続け方は、人それぞれ違います。誰かにとっての正解が、あなたにとっての正解とは限りません。30日間の記録は、自分だけの「続く仕組み」をつくるための材料です。

うまくいったことは残し、合わなかったことは気軽に変えていきましょう。30日ごとに振り返りと調整を繰り返すことで、体を動かす習慣は、少しずつ自分の生活になじんでいきます。
