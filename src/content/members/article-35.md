90日間、約3か月の記録は、季節の移り変わりや、仕事・家庭のさまざまな出来事を含んだ「自分の生活の歴史」です。1か月ごとの振り返りでは見えなかった、長い目で見た変化や、自分らしいパターンが浮かび上がってきます。

3か月間記録を続けてきたこと自体が、大きな成果です。途中で途切れた時期があったとしても、また再開してここまで来たのなら、それは立派な継続です。この記事では、90日間の記録を活用して、自分だけの振り返りを行う方法を紹介します。最後には、これからの習慣づくりに役立つ「習慣プロフィール」をつくります。

## 90日振り返りの3つの視点

| 視点 | 問いかけ |
|---|---|
| 変化 | 90日前と比べて、何が変わったか |
| 定着 | 意識しなくても続くようになった習慣は何か |
| パターン | 調子が崩れやすい時期やきっかけはあるか |

この3つの視点を意識しながら、4つのステップで振り返りを進めていきましょう。1時間ほど、落ち着いて取り組める時間を確保してください。

## ステップ1：3か月の月末まとめを並べる

[記事34](/members/articles/article-34/)の月末まとめシートを3か月分並べます。シートがない場合は、各月の記録を見返しながら、「今月の特徴」を一言ずつ書き出しましょう。

| 月 | この月を一言で | 主な出来事 |
|---|---|---|
| 1か月目 | 記入例：記録に慣れた月 | 新しい仕事が始まった |
| 2か月目 |  |  |
| 3か月目 |  |  |

3か月を並べてみると、「1か月目は張り切っていたけれど、2か月目に少し疲れが出た」「3か月目には自分のペースがつかめた」といった、大きな流れが見えてきます。

## ステップ2：「定着した習慣」を見つける

90日前には意識して行っていたことが、今では自然にできていることはありませんか。それは、あなたの生活にしっかり根づいた習慣です。

- 例：朝起きたらカーテンを開ける
- 例：昼休みに10分歩く
- 例：寝る前にスマートフォンを置く
- 例：毎晩、気分を記録する
定着した習慣を見つけたら、ぜひ自分を褒めてあげてください。新しい習慣を身につけるのは、簡単なことではありません。定着した習慣は、これからも生活を支えてくれる大切な財産です。

## ステップ3：自分の「崩れやすいパターン」を知る

次に、習慣が崩れた時期に目を向けます。

- 繁忙期、季節の変わり目、旅行や行事の後などに、記録や習慣が乱れていないか確認します
- 崩れたきっかけは何だったかを振り返ります
- 崩れた後、どのくらいで元に戻れたか、何がきっかけで戻れたかも見てみましょう
崩れること自体は、誰にでもある自然なことです。大切なのは、「戻り方」を知っておくことです。たとえば、「記録だけは続けていたので、すぐに戻れた」「最低限ルールに切り替えたら、ゼロにならずに済んだ」など、自分なりの戻り方が見つかれば、次に崩れたときにも慌てずに済みます。

## ステップ4：自分だけの「習慣プロフィール」をつくる

90日間の振り返りの集大成として、自分だけの「習慣プロフィール」をつくりましょう。

| 項目 | 記入欄 |
|---|---|
| 私が続けやすい時間帯 |  |
| 私に合う記録の方法 |  |
| 定着した習慣 |  |
| 崩れやすいときのサイン |  |
| 崩れたときの戻り方 |  |
| 私の気分が上がる過ごし方 |  |
| これから育てたい習慣 |  |

習慣プロフィールは、自分の取扱説明書のようなものです。新しい習慣を始めるときや、調子が崩れたときに見返すと、自分に合った方法を選ぶ助けになります。

## まとめ

90日間の振り返りは、自分を深く知るための特別な時間です。3か月間の記録には、自分でも気づいていなかった自分の姿が映っています。

完成した習慣プロフィールは、次の90日間の計画づくりにそのまま活用できます。計画のつくり方は、[記事40](/members/articles/article-40/)で詳しく紹介しています。
