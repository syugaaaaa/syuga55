「自分の時間がほしい」。そう思っていても、意識しなければ1週間はあっという間に過ぎてしまいます。仕事や家事、家族の予定を優先しているうちに、気がつけば週末も終わっていて、自分のための時間はほとんどなかった、ということも珍しくありません。

自分のための時間は、空いた時間ができるのを待っていても、なかなか生まれません。だからこそ、あらかじめ1週間のセルフケア計画を立てて、自分の時間を予定として確保することが大切です。この記事では、1週間のセルフケア計画の立て方と、振り返りの方法を紹介します。

## 計画を立てる前に

まず、先週1週間を振り返ってみましょう。

- 自分のためだけに使えた時間は、どのくらいあったか
- その時間に何をしたか、満足できたか
- 本当はやりたかったのに、できなかったことは何か
- 1週間の中で、比較的時間をとりやすい曜日や時間帯はいつか
振り返ってみると、「自分の時間は思っていたより少なかった」「スマートフォンを見ているうちに時間が過ぎていた」など、さまざまな気づきがあるはずです。

## セルフケアを2種類に分けて考える

1週間のセルフケアは、次の2種類に分けて考えると計画しやすくなります。

- 毎日の小さなケア（5〜10分）：寝る前のストレッチ、好きなお茶を淹れる、日記を書くなど、毎日続けられる短いケア。
- 特別なケア（30分〜半日）：ゆっくり入浴する、趣味に没頭する、友人と会う、外出するなど、少し時間をかけるケア。
毎日の小さなケアで日々の疲れをこまめにリセットし、特別なケアで心をしっかり満たす。この組み合わせが、1週間を心地よく過ごすコツです。

## 1週間のセルフケア計画表（例）

| 曜日 | 毎日の小さなケア（5〜10分） | この日の特別なケア |
|---|---|---|
| 月 | 寝る前のストレッチ |  |
| 火 | 好きなお茶を淹れる | 夜にゆっくり入浴する |
| 水 | 寝る前のストレッチ |  |
| 木 | 日記を3行書く | 友人に連絡する |
| 金 | 好きな音楽を聴く |  |
| 土 | 朝の散歩 | 半日、予定を入れない |
| 日 | 1週間の振り返り | 来週の計画を立てる |

## 計画づくりのポイント

- 毎日の小さなケアを1つ決める：短時間で、毎日続けられるものを選びます。曜日ごとに変えても構いません。
- 週に2〜3回、特別なケアを入れる：入浴、趣味、外出など、少し時間をかけるものを入れます。忙しい週は1回でも十分です。
- 週末に「余白」を残す：予定を詰め込まず、その日の気分で過ごせる時間をつくります。
- 家族や周りに伝える：「この時間は自分の時間」と家族と共有すると、確保しやすくなります。
- 手帳やカレンダーに書き込む：仕事の予定と同じように、セルフケアの時間も書き込みましょう。

## 計画通りにいかなかったら

急な予定や体調の変化で、計画通りにいかない週もあるでしょう。それは当然のことです。できなかったケアは、別の日に振り替えたり、短い時間に縮めたりして柔軟に調整しましょう。計画は、自分を縛るためのものではなく、自分の時間を守るための目安です。

## 週末の振り返り

| 振り返り項目 | 記入欄 |
|---|---|
| 実行できたセルフケア |  |
| 一番気持ちが満たされたこと |  |
| できなかったことと理由 |  |
| 来週試したいこと |  |

振り返りは、日曜日の夜などに5〜10分で行いましょう。「一番気持ちが満たされたこと」を書き出すことで、自分にとって本当に大切なセルフケアが見えてきます。

## まとめ

自分のための時間は、待っていても生まれません。計画に書き込むことで、その時間を守りやすくなります。計画通りにいかない週があっても大丈夫です。

毎週少しずつ調整しながら、自分を大切にする1週間を重ねていきましょう。その積み重ねが、心のゆとりと、自分らしい毎日につながっていきます。
