90日間、本当にお疲れさまでした。忙しい日も、疲れた日も、記録が途切れた日もあったかもしれません。それでも、ここまでたどり着いたあなたの手元には、自分の生活を知るための大切な材料がそろっています。

この記事は、会員限定記事シリーズの締めくくりです。90日間を振り返り、これからの習慣計画をつくりましょう。振り返りは「終わり」ではなく、次の90日間を、もっと自分らしく過ごすための「始まり」です。1時間ほど、ゆっくりと時間をとって取り組んでみてください。

## ステップ1：90日間の自分をねぎらう

まずは、ここまで取り組んだ自分を認めることから始めます。次の質問に答えてみましょう。

- 90日間で、一番うれしかった変化は何か
- 一番続けられた習慣は何か
- 大変だった時期を、どう乗り越えたか
- 90日前の自分に、今なら何と声をかけたいか
できなかったことに目を向ける前に、できたことをしっかり認めましょう。小さな変化でも、それはあなたが積み重ねてきた日々の成果です。

## ステップ3：習慣を3つに分ける

90日間で取り組んできた習慣を、次の3つに分けてみましょう。

| 分類 | 内容 | 記入欄 |
|---|---|---|
| 続ける習慣 | 定着して、これからも続けたいもの |  |
| 育てる習慣 | 途中だけれど、さらに続けたいもの |  |
| 手放す習慣 | 合わなかった、今は必要ないもの |  |

「手放す習慣」を決めることも、大切な選択です。合わない方法を無理に続けるより、自分に合うものに時間とエネルギーを使いましょう。手放したからといって、それが失敗だったわけではありません。「自分には合わない」と分かったこと自体が、90日間の収穫です。

## ステップ4：次の90日間の計画をつくる

いよいよ、次の90日間の計画をつくります。

| 項目 | 記入欄 |
|---|---|
| 次の90日間で大切にしたいこと（一言） |  |
| 1か月目に取り組むこと |  |
| 2か月目に取り組むこと |  |
| 3か月目に取り組むこと |  |
| 忙しい日の最低限ルール |  |
| 崩れたときの戻り方 |  |
| 振り返りの日（毎月） |  |

「次の90日間で大切にしたいこと」は、具体的な目標ではなく、心構えのようなもので構いません。たとえば「無理をしない」「自分を褒める」「睡眠を最優先にする」など、迷ったときに立ち返る言葉を書いておきましょう。

## 計画づくりのポイント

- 新しく始めることは、1か月に1つまで：欲張らず、1つずつ確実に育てていきます。
- 季節の変化や予定されている行事も考慮する：年末年始や繁忙期など、生活が変わる時期をあらかじめ計画に入れておきます。
- 記録の方法は、続けやすい形に見直してよい：90日間で分かった、自分に合う記録の方法を取り入れましょう。
- 「続ける習慣」は計画の土台にする：すでに定着した習慣は、これからも生活の土台として大切にします。

## まとめ

90日間の記録は終わりではなく、これからの自分をつくる出発点です。記録を通して知った自分の傾向、定着した習慣、崩れたときの戻り方。それらはすべて、これからの毎日を支えてくれる財産です。

自分に合った習慣を少しずつ育てながら、心地よい毎日を重ねていきましょう。次の90日間も、記事36〜39を道しるべにして、あなたらしいペースで進んでください。
