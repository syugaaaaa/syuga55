食事・睡眠・運動は、健康を支える「三本柱」です。そしてこの3つは、それぞれが独立しているのではなく、互いに影響し合っています。よく眠れた日は食事のリズムが整いやすく、体を動かした日は夜の寝つきが良くなる。反対に、寝不足の日は間食が増え、体を動かす気力も落ちやすくなります。

だからこそ、3つを別々に見直すより、まとめて記録することで、そのつながりが見えてきます。このチャレンジでは、1日1分でつけられるシンプルな記録シートを使って、30日間を過ごします。30日後には、自分にとっての「三本柱のバランス」が分かるようになることを目指しましょう。

## 1日1分の記録シート

| 日付 | 食事（3食・野菜） | 睡眠（時間・目覚め） | 運動（内容・時間） | 今日のひとこと |
|---|---|---|---|---|
| 記入例 | 3食○／野菜2回 | 6.5時間／3 | 散歩15分 | 少し肩が軽い |
| 1日目 |  |  |  |  |
| 2日目 |  |  |  |  |
| 3日目 |  |  |  |  |

※目覚めの評価は5段階（1：良くない〜5：とても良い）で記録します。

このシートを手帳に写したり、スマートフォンのメモに同じ形式でつけたりして使いましょう。書くタイミングは、寝る前がおすすめです。睡眠については、前の晩の分を記録します。

## 30日間の4つのステージ

- 1〜7日目：ありのまま記録
- 生活は変えず、普段通りに過ごして記録だけを続けます。
- 8〜14日目：1つの柱を整える
- 3つのうち、最も整えたい柱を1つ選び、小さな目標を立てます。
- 15〜21日目：つながりを観察する
- 整えた柱が、他の2つにどう影響しているかを観察します。
- 22〜30日目：3つのバランスを整える
- 2つ目の柱にも小さな目標を加え、全体のバランスを整えます。

## ステージ1：ありのまま記録

最初の1週間は、記録に慣れることと、今の自分の生活を知ることが目的です。「良く見せよう」とせず、ありのままを書きましょう。この1週間の記録が、後で変化を比べるための基準になります。

## ステージ2：1つの柱を整える

1週間の記録を見て、3つの柱のうち、一番整えたいものを1つ選びます。目標の例を挙げます。

- 食事：1日2回は野菜・きのこ・海藻をとる、朝食を抜かない
- 睡眠：23時までに布団に入る、起床時刻を一定にする
- 運動：1日15分歩く、1時間に1回立ち上がる

## ステージ3：つながりを観察する

1つの柱を整え始めると、他の柱にも変化が表れることがあります。「早く寝るようになったら、朝食をとる余裕ができた」「歩くようになったら、寝つきが良くなった」など、つながりに気づいたら、「今日のひとこと」の欄にメモしておきましょう。

## ステージ4：3つのバランスを整える

最後の週は、2つ目の柱にも小さな目標を加えます。ただし、1つ目の目標が続いていることが前提です。無理だと感じたら、1つ目の目標を続けることを優先しましょう。

## つながりを見つける質問

- よく眠れた日の翌日、食事や運動はどうだったか
- 体を動かした日の夜、寝つきはどうだったか
- 食事のリズムが乱れた日、睡眠に影響はあったか
- 3つが全部整っていた日は、どんな1日だったか

## まとめ

3つの柱をまとめて記録すると、「1つを整えると、他も整いやすい」という実感が得られます。どこから手をつければ全体が良くなるのか、自分にとっての「起点」が見つかれば、これからの習慣づくりがぐっと楽になります。

このチャレンジで見つけたつながりを、90日間の取り組み（[記事39](/members/articles/article-39/)）にも活かしていきましょう。
