1か月、30日分の記録は、生活習慣を見直すための豊富な材料です。毎週の振り返りでは気づけなかった、月の前半と後半の違いや、特定の出来事が生活に与えた影響など、より大きな流れが見えてきます。

せっかく1か月記録を続けたのですから、月末には少し時間をとって、記録を整理しておきましょう。「今月の自分」をまとめておくことで、来月の過ごし方を考えやすくなります。また、毎月続けることで、季節や生活の変化による違いも見えてくるようになります。この記事では、30分ほどでできる月末振り返りの進め方を紹介します。

## 月末振り返りの進め方（30分）

- 数を数える（5分）：記録できた日数、目標を達成できた日数を数えます。
- 週ごとに比べる（10分）：第1週〜第4週の記録を比べ、調子の波を確認します。
- 良かったことを書く（5分）：今月できたこと、続いたことを3つ書き出します。
- 気づきを書く（5分）：今月見えた傾向や、改善したいことをまとめます。
- 来月の目標を決める（5分）：取り組むことを1〜2つに絞ります。

## ステップ1：数を数える

まずは、事実を数字で確認します。記録できた日数、目標を達成できた日数、体を動かした日数などを数えましょう。数字にすることで、感覚だけでは分からない事実が見えてきます。「ほとんど続かなかった気がしていたけれど、実は20日も記録できていた」という発見があるかもしれません。

## ステップ2：週ごとに比べる

| 項目 | 第1週 | 第2週 | 第3週 | 第4週 |
|---|---|---|---|---|
| 記録できた日数 |  |  |  |  |
| 睡眠の満足度（平均） |  |  |  |  |
| 体を動かした日数 |  |  |  |  |
| 気分（平均） |  |  |  |  |
| 主な出来事 |  |  |  |  |

週ごとに比べると、「第3週は仕事が忙しくて、睡眠も気分も下がっていた」「第4週は少し持ち直した」といった、1か月の中の波が見えてきます。主な出来事も書き添えておくと、波の理由が分かりやすくなります。

## ステップ3・4：良かったことと気づきを書く

振り返りでは、つい「できなかったこと」に目が向きがちです。でも、まずは「できたこと」から書き出しましょう。できたことを確認すると、自信がつき、来月も続けようという気持ちが湧いてきます。

その後で、今月見えた傾向や、改善したいことを書きます。改善したいことは、自分を責めるためではなく、来月をより良くするための材料として書き出しましょう。

## 月末まとめシート

| 項目 | 記入欄 |
|---|---|
| 今月できたこと・続いたこと |  |
| 今月見えた傾向 |  |
| うまくいかなかったことと理由 |  |
| 来月取り組むこと（1〜2つ） |  |
| 来月の自分へのひとこと |  |

「来月の自分へのひとこと」は、少し照れくさいかもしれませんが、ぜひ書いてみてください。「今月はよく頑張ったね」「来月は無理せずいこう」など、自分にかけたい言葉を書きます。翌月の振り返りのときに読み返すと、励みになります。

## ステップ5：来月の目標を決める

来月の目標は、1〜2つに絞りましょう。目標が多すぎると、どれも中途半端になってしまいます。今月の気づきの中から、「これが整うと、他も良くなりそう」と思えるものを選ぶのがおすすめです。

## 振り返りを楽しむ工夫

- 好きな飲み物を用意して、ゆったりした気持ちで行う
- 月末の同じ日（例：最終日曜日）を「振り返りの日」として予定に入れる
- 今月のベスト習慣に、自分なりの「賞」をつける
- 振り返りシートを1冊のノートにまとめ、毎月の記録を積み重ねる

## まとめ

月末の振り返りは、1か月頑張った自分をねぎらう時間でもあります。課題ばかりに目を向けず、できたことをしっかり認めたうえで、来月の小さな目標につなげていきましょう。
