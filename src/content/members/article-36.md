「美容も健康も気になるけれど、何から見直せばいいか分からない」。そんな方のために用意したのが、この7日間のセルフチェックプログラムです。スキンケア、食事、睡眠、運動、心のゆとり。気になることはたくさんあっても、全部を一度に変えることはできません。まずは、今の自分の生活の全体像を知ることから始めましょう。

このプログラムでは、1日1テーマ、5〜10分で取り組める内容を用意しています。7日後には、今の自分の生活習慣の全体像と、最初に取り組むべきテーマが見えてくるはずです。会員記事の他のカテゴリとも連動しているので、気になったテーマは関連記事でさらに深めることができます。

## 7日間のスケジュール

| 日 | テーマ | 取り組むこと | 関連記事 |
|---|---|---|---|
| 1日目 | 記録の準備 | 記録の目的を一言で書き、記録方法を決める | 31 |
| 2日目 | 美容 | 朝晩のスキンケアの流れと肌の調子を書き出す | 1、2 |
| 3日目 | 食事 | 1日の食事と間食をすべてメモする | 12、13 |
| 4日目 | 睡眠 | 就寝・起床時刻と目覚めの気分を記録する | 16、19 |
| 5日目 | 活動 | 歩数と、座っていた時間をざっくり記録する | 22、24 |
| 6日目 | 心 | 気分を5段階で記録し、自分のための時間を書き出す | 26、28 |
| 7日目 | 振り返り | 6日間を見返し、最初に取り組むテーマを決める | 33 |

## 各日の取り組みのポイント

1日目（記録の準備）：ノート、アプリ、手帳など、7日間使う記録の道具を決めます。最初のページに「このプログラムで知りたいこと」を一言書いておきましょう。

2日目（美容）：朝と夜のスキンケアで使っているアイテムと順番を書き出します。あわせて、今日の肌の調子を5段階で評価し、気になることをメモします。

3日目（食事）：1日の食事と間食を、時間と一緒にすべてメモします。量や細かい内容は気にせず、何を食べたかを書くだけで十分です。

4日目（睡眠）：昨夜の就寝時刻と今朝の起床時刻、目覚めの気分を記録します。寝る前に何をしていたかも書いておくと、振り返りに役立ちます。

5日目（活動）：スマートフォンなどで歩数を確認し、座っていた時間をざっくり書き出します。体を動かした場面もメモしましょう。

6日目（心）：今日の気分を5段階で記録します。また、この1週間で自分のためだけに使えた時間を書き出してみましょう。

7日目（振り返り）：6日間の記録を見返し、次のセルフチェックを行います。

## 7日目のセルフチェック

各テーマを、今の満足度で5段階評価してみましょう。

| テーマ | 満足度（1〜5） | 気づいたこと |
|---|---|---|
| 美容・スキンケア |  |  |
| 食事 |  |  |
| 睡眠 |  |  |
| 活動・運動 |  |  |
| 心のゆとり |  |  |

満足度は、他の人と比べるものではありません。今の自分が、そのテーマについてどう感じているかを素直に評価しましょう。

## 最初に取り組むテーマの選び方

- 満足度が一番低いテーマ
- 「ここが整うと、他も良くなりそう」と感じるテーマ
- 一番「変えたい」と気持ちが動くテーマ
どれを選んでも正解です。迷ったら、多くの習慣の土台になる「睡眠」から始めるのもおすすめです。睡眠が整うと、肌の調子や食欲、気分など、他のテーマにも良い影響が広がりやすくなります。

## 続けて取り組むなら

7日間で見えたテーマを、次の30日間でじっくり見直したい方は、[記事37](/members/articles/article-37/)「30日間で取り組む、美容・健康習慣の見直しプログラム」に進みましょう。食事・睡眠・運動をまとめて整えたい方は、[記事38](/members/articles/article-38/)の30日間チャレンジもおすすめです。

## まとめ

セルフチェックは、今の自分を責めるためではなく、「どこから始めるか」を決めるための地図づくりです。満足度が低いテーマがあっても、それは伸びしろがあるということ。7日間で、自分の生活を見つめ直す第一歩を踏み出しましょう。
