90日間、約3か月分の記録には、1週間や1か月では見えなかった「自分のパターン」が表れます。たとえば、「毎月同じ時期に生活が乱れやすい」「季節が変わると体の軽さが変わる」「忙しい時期の後は、元に戻るまでに2週間かかる」といった、長い目で見なければ分からない傾向です。

90日間の振り返りは、結果の良し悪しを判断するためのものではありません。「自分はどんなときに整いやすく、どんなときに崩れやすいのか」を知り、次の90日間に活かすためのものです。この記事では、90日分の記録から自分の体型管理パターンを見つける方法を紹介します。

## 振り返りの準備

- 90日分の記録（ノート、アプリ、写真など）を手元にそろえる
- 1時間ほど、落ち着いて取り組める時間を確保する
- 月ごとの振り返りメモ（[記事34](/members/articles/article-34/)参照）があれば、一緒に用意する
記録が抜けている期間があっても問題ありません。抜けていた期間そのものも、「記録が途切れやすい時期」として大切な情報になります。

## 90日間の振り返りの流れ

- 記録を月ごとに並べる：1か月目・2か月目・3か月目の記録を並べて、全体を見渡します。
- 月ごとの特徴を一言で書く：「忙しくて歩けなかった月」「睡眠が整った月」「外食が多かった月」など、その月を一言で表します。
- 変化のきっかけを探す：体の軽さや服の着心地が良くなった時期、崩れた時期に、生活の中で何があったかを確認します。
- 自分のパターンを言葉にする：「〇〇のときに△△になりやすい」という形でまとめます。

## よく見られるパターンの例

- 仕事が忙しい週は、夕食が遅くなり、翌朝の体が重い
- 週末に予定が多いと、月曜日の記録が抜けやすい
- よく歩いた週は、睡眠の質も良いと感じる
- 季節の変わり目に、生活リズムが崩れやすい
- 記録が途切れると、食事のリズムも乱れやすい
- 行事や旅行の後、元のペースに戻るまで1週間ほどかかる
自分にも当てはまるものがないか、記録と照らし合わせてみましょう。

## 「崩れたとき」と「戻ったとき」に注目する

90日間の中で、習慣が崩れた時期はありませんでしたか。崩れること自体は、誰にでもある自然なことです。注目したいのは、「何がきっかけで崩れたか」と「どうやって戻ったか」です。

たとえば、「繁忙期に崩れたけれど、記録だけは続けていたので、繁忙期が終わってすぐに戻れた」という経験があれば、それはあなたにとっての大切な「戻り方」です。この戻り方を知っておくと、次に崩れたときにも慌てずに対処できます。

## パターンを次に活かす

自分のパターンが分かると、先回りした対策が立てられます。

| 見つかったパターン | 次の90日間の対策 |
|---|---|
| 記入例：繁忙期は夕食が遅くなる | 夕方に軽く食べられるものを用意する |
| 記入例：週明けに記録が抜けやすい | 日曜の夜に1週間の予定を確認する |
|  |  |
|  |  |

## まとめ

90日間の記録は、自分の体と生活を知るための貴重な資料です。3か月続けてきたこと自体が、大きな成果といえます。結果の数字だけでなく、「どんなときに整いやすく、どんなときに崩れやすいか」に目を向けることで、これからの体型管理はもっと自分らしいものになっていきます。

見つけたパターンと対策は、次の90日間の計画にそのまま活かしましょう。計画のつくり方は、[記事40](/members/articles/article-40/)で詳しく紹介しています。
