1週間の記録では見えにくかったことも、30日間の食事記録になると、はっきりと見えてくるようになります。平日と週末の違い、月の前半と後半の違い、忙しい時期とゆとりのある時期の違いなど、自分の食習慣の「型」が浮かび上がってくるのです。

せっかく30日間記録を続けたのなら、そのまま次の月に進むのではなく、一度立ち止まって整理してみましょう。この記事では、月末に食事記録を振り返り、次の1か月の食生活に活かすための方法を紹介します。

## 振り返りの準備

- 30日分の記録（ノート、アプリ、写真など）を手元に用意する
- 30分ほど、落ち着いて見返せる時間を確保する
- 好きな飲み物を用意して、リラックスした気持ちで取り組む
- 評価ではなく「観察」のつもりで読む
振り返りのときに大切なのは、自分を責めないことです。「こんなに外食が多かった」「野菜が足りていなかった」と思っても、それは単なる事実です。事実を知ることができたこと自体を、前向きに受け止めましょう。

## 4つの視点で整理する

| 視点 | 確認すること | 記入欄 |
|---|---|---|
| 食事のリズム | 食事を抜いた日、時間が大きくずれた日は何日あったか |  |
| 食事の内容 | 主菜・副菜がそろった食事はどのくらいあったか |  |
| 間食 | 間食が多かった時間帯やきっかけは何か |  |
| 曜日・状況 | 平日と週末、忙しい日とゆとりのある日の違い |  |

## 視点ごとの見方のヒント

食事のリズムでは、カレンダーに食事を抜いた日を印をつけてみると、特定の曜日や時期に集中しているかどうかが分かります。

食事の内容では、1週間ごとに「主菜・副菜がそろった食事の回数」を数えて比べると、変化が見えやすくなります。

間食では、[記事13](/members/articles/article-13/)で紹介した「きっかけ」と「満足度」に注目しましょう。満足度の低い間食が多い時間帯があれば、そこが見直しのポイントです。

曜日・状況では、平日と週末を分けて見てみましょう。多くの人は、週末に食事のリズムが変わりやすい傾向があります。

## 「良かったこと」から書き出す

振り返りでは、つい課題ばかりに目が向きがちです。まずは30日間でできたこと、続いたことを3つ書き出しましょう。小さなことで構いません。

例：

- 朝食を毎日とれた
- 週に3回は自炊できた
- 野菜スープの作り置きが習慣になった
- 夜遅くの間食が減った
良かったことを先に確認すると、前向きな気持ちで次の目標を考えられます。

## 次の30日間の目標を1つ決める

整理した結果から、次の30日間に取り組むことを1つだけ選びます。

| 気づいたこと | 次の30日の目標 |
|---|---|
| 記入例：週末は朝食が遅く、昼食を抜きがち | 週末も10時までに朝食をとる |
| 記入例：残業の日は夕食がコンビニの麺類だけ | 麺類にサラダかゆで卵を1品足す |
|  |  |

目標は、「少し頑張ればできる」くらいの大きさにしましょう。

## 記録を続けるか迷ったら

30日間で傾向がつかめたら、毎日の詳しい記録を少し簡単にしても構いません。たとえば、「平日のみ記録する」「夕食だけ記録する」「目標に関する項目だけ記録する」などです。そして、生活が大きく変わったときや、調子が気になるときに、また詳しく記録すればよいのです。記録は、自分に合った形で長く付き合っていく道具です。

## まとめ

30日間の食事記録は、自分の食習慣を客観的に知る貴重な材料です。良かったことを認め、変えたいことを1つ選ぶ。このシンプルなサイクルを毎月繰り返すことで、食生活は少しずつ、確実に自分らしく整っていきます。
