パソコンに向かう仕事、通勤の電車や車の中、食事の時間、そして夜のテレビやスマートフォン。1日を振り返ってみると、私たちは思っている以上に長い時間を座って過ごしています。「運動はしていないけれど、座っているだけだから体は休まっているはず」と思うかもしれません。

しかし、同じ姿勢で長時間座り続けていると、体がこわばったり、脚がむくんだり、気分がどんよりしたりしやすくなります。運動の時間をつくるのと同じくらい、「座りっぱなしの時間を区切ること」も大切な活動習慣です。この記事では、座りっぱなしの時間を見直し、生活の中に小さな動きを取り入れる方法を紹介します。

## まずは座っている時間を知る

1日のうち、座っている時間をざっくり書き出してみましょう。

| 時間帯 | 主な過ごし方 | 座っていた時間 |
|---|---|---|
| 午前 | パソコン作業 | 約3時間 |
| 午後 | 会議、事務作業 | 約3時間 |
| 夜 | 食事、テレビ、スマートフォン | 約2時間 |
| 移動 | 通勤の電車・車 | 約1時間 |

合計してみると、予想より長いことに驚くかもしれません。まずはこの「気づき」が大切な第一歩です。

## 座りっぱなしを区切る工夫

- 30〜60分に1回立ち上がる：タイマーやスマートフォンの通知を活用して、立ち上がるきっかけをつくりましょう。
- 立ったままできることを探す：電話、資料の確認、歯磨き、洗濯物をたたむなど、立ってできることは立って行います。
- 飲み物を取りに行く：水やお茶を小さなコップにして、取りに行く回数を自然と増やします。
- テレビの合間に動く：CMや番組の区切りで立ち上がり、伸びをしたり、部屋の中を歩いたりします。
- 会議や打ち合わせの合間に：会議が終わったら、次の作業の前に一度立ち上がって体を伸ばします。

## 立ち上がったら何をする？

立ち上がるだけでも十分ですが、せっかくなら少し体を動かしてみましょう。

- 両手を頭の上に伸ばして、全身で伸びをする
- 肩を大きく後ろに回す
- その場で足踏みを30回する
- 窓際まで歩いて、外の景色を眺める
1〜2分の小さな動きでも、体と頭がリフレッシュされます。

## 座ったままできる「ちょこっと活動」

会議中や移動中など、立ち上がれない場面もあります。そんなときは、座ったままでも体を動かせます。

- かかとの上げ下げを10回
- つま先の上げ下げを10回
- 両肩を大きく後ろに5回回す
- 背すじを伸ばして深呼吸を3回
- 足首をゆっくり回す
周りの人に気づかれにくい動きなので、職場や電車の中でも取り入れやすいでしょう。

## 1日の「立ち上がり回数」を記録する

| 日付 | 立ち上がった回数 | 工夫したこと |
|---|---|---|
| 記入例：月曜日 | 8回 | 1時間ごとにタイマーを設定 |
|  |  |  |
|  |  |  |

回数に正解はありません。昨日より1回多く立ち上がれたら十分です。記録をつけていると、「今日は座りっぱなしだったな」と気づけるようになり、自然と立ち上がる意識が高まります。

## 姿勢にも目を向ける

座っているときの姿勢も大切です。背中が丸まっていたり、脚を組んだままだったりすると、体の一部に負担がかかりやすくなります。椅子に深く腰かけ、足の裏を床につけ、背すじを軽く伸ばすことを意識しましょう。立ち上がるたびに、座り直して姿勢をリセットするのもおすすめです。

## まとめ

座りっぱなしを見直すことは、運動が苦手な方でも今日から取り組める活動習慣です。特別な時間も場所も必要ありません。「長く座っていたら、一度立つ」を合言葉に、生活の中に小さな動きを散りばめていきましょう。

小さな動きの積み重ねが、体の軽さや、1日の終わりの疲れ方を少しずつ変えていきます。
